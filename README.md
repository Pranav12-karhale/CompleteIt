## 🚀 Overview

The **CompleteIt** is a beautifully designed, lightweight web application that helps you keep track of your daily tasks. It features a premium dark theme, smooth micro-interactions, and a responsive layout. The project is completely containerized with Docker.

## ✨ Features

- **Sleek UI:** A premium dark-mode interface designed with the 'Inter' font and smooth box shadows.
- **Micro-Interactions:** Subtle hover effects and transition animations for a dynamic user experience.
- **Task Management:** Easily add new tasks, mark them as completed with a strike-through, or delete them.
- **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript.

3. **View the App**:
   Open your browser and navigate to [http://localhost:8080](http://localhost:8080).

## 📂 Project Structure

```text
├── index.html       # The main HTML structure
├── todo.css         # Styling, layout, and dark theme
├── todo.js          # Logic for adding, completing, and deleting tasks
├── Dockerfile       # Instructions for building the Nginx Docker image
└── .dockerignore    # Files excluded from the Docker build context
```

## 🎨 Design Philosophy

This project prioritizes **Visual Excellence**. The aesthetic choices move away from generic default colors, opting for a curated, harmonious dark palette (`#121212`, `#1e1e1e`, `#272727`). Focus outlines use a vibrant accent color (`#646cff`) to ensure accessibility while maintaining a premium feel.
